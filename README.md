# A-share Picker

A 股日线研究与候选筛选工具。它把 2026 年 7–9 月（或任意日期区间）的行业资金流、行业内成长、圆弧底完成度和大单资金异动放在同一个可复现流程中，并输出 1–3 个交易日策略候选及回测摘要。

> 本项目仅用于数据研究和策略验证，不构成投资建议。所谓“主力资金”是东方财富按成交单大小统计的代理指标，不代表可以验证的机构持仓或真实建仓行为。任何推荐都可能亏损，请自行核验行情、停牌、涨跌停、财报和交易成本。

## 功能

- 下载沪深京 A 股前复权日线 OHLCV、成交额、换手率并落盘缓存
- 将行业主力净流入按周（周五为周末）汇总和排名
- 以营收同比、净利润同比为主，60 日相对强度为缺失值后备，筛出行业内高于平均成长
- 用对数价格二次曲线、拟合优度、回升幅度和近期上涨确认圆弧底
- 用近 10 日主力净流入、正流入天数、60 日 z-score 和量能识别资金异动
- 生成下一交易日开盘候选，并用止盈、止损、最长 3 日持有规则进行日线级保守回测
- GitHub Actions 每个交易日北京时间约 16:30 自动刷新报告，也支持手动运行

## 快速开始

要求 Python 3.11 或更高版本。

~~~bash
git clone https://github.com/Yaohuizhongliu/a-share-picker.git
cd a-share-picker
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -e .
ashare-picker run --config config/default.yml --as-of 2026-09-14
~~~

报告默认写到 `reports/latest/`：

| 文件 | 内容 |
|---|---|
| `weekly_sector_flows.csv` | 逐周行业主力净流入、正流入天数、周排名 |
| `candidates.csv` | 股票各因子、行业均值、综合分 |
| `recommendations.csv` | 当日满足硬条件的 1–3 日观察候选 |
| `backtest_trades.csv` | 技术面与资金面触发后的历史交易明细 |
| `backtest_summary.csv` | 分持有期胜率、平均/中位收益、最大单笔回撤 |
| `report.md` | 中文汇总报告和数据质量提示 |

仅下载和检查某只股票的日线：

~~~bash
ashare-picker download --symbol 600519 --start 20260701 --end 20260914
~~~

运行测试：

~~~bash
pip install -e ".[dev]"
pytest
~~~

## 默认研究口径

默认区间为 2026-07-01 至 2026-09-30，但结束日自动截断为 `--as-of` 与当天日期中较早者，因此 2026 年 9 月尚未结束时不会使用未来数据。信号计算额外向前下载约 180 个自然日。

1. **行业资金流**：行业每日“主力净流入-净额”按周求和；正值只表示大单口径净流入。
2. **成长**：营收同比和净利润同比先进行 5%/95% 缩尾，再在行业内比较；财报缺失时才使用 60 日价格动量。
3. **圆弧底**：60 日对数收盘价拟合开口向上的二次曲线，要求底部位于窗口合理位置、拟合度达标、价格从底部回升且近 5 日上涨。
4. **资金异动**：近 10 日主力净流入为正、正流入日占比达标，且相对 60 日基线出现异常；成交量放大用于加分。
5. **推荐**：行业当周净流入为正、成长高于行业平均，且圆弧底或资金异动至少一个成立，再按综合分排序。
6. **交易模拟**：信号日后一个交易日开盘买入；默认止损 3%、止盈 6%、最多持有 3 日。同日同时触及止损和止盈时按先止损处理，以减少日线数据无法确定盘中顺序造成的乐观偏差。

所有阈值都在 `config/default.yml` 中，可审计、可修改。默认限制每个领先行业按成交额研究 25 只股票，以控制公开接口压力；设为 0 可取消限制。

## 数据源与限制

- [AKShare 日线接口](https://akshare.akfamily.xyz/data/stock/stock.html#id27)：东方财富沪深京 A 股日频数据
- [AKShare 行业与个股资金流接口](https://akshare.akfamily.xyz/data/stock/stock.html#id190)：个股接口通常仅提供近约 100 个交易日
- [AKShare 年报季报接口](https://akshare.akfamily.xyz/data/stock/stock.html#id159)：指定报告期业绩报表
- [AKShare 项目](https://github.com/akfamily/akshare)：MIT 许可的第三方数据接口库

公开网页接口可能变更、限流或暂时不可用。下载器对每个端点进行重试并缓存成功结果；单个行业或股票失败时记录警告并继续，报告会列出覆盖率。行业成分取运行时快照，因此历史回测存在幸存者偏差；前复权历史也可能随除权事件变化。完整策略回测结果不能代表未来表现。

## 每日自动运行

仓库已包含 `.github/workflows/daily.yml`。在 GitHub 仓库的 **Actions** 页面启用工作流后，可以：

- 点击 **Run workflow** 立即生成一次报告；
- 等待工作日定时任务自动生成；
- 在 `reports/latest/report.md` 查看最新结果。

工作流只提交派生报告，不提交本地缓存。若上游接口临时失败，工作流会保留日志，不会把空报告当作成功结果。
